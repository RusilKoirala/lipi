Lipi is young. These are the gaps you are most likely to notice, roughly in the order they will be filled.

## Coming next

- **A REPL.** Run `lipi` with no file and get a `lipi>>` prompt to try lines one at a time.
- **Loops.** A `jabasamma` ("as long as") loop, so counting doesn't need recursion.
- **Arrays.** Lists like `[1, 2, 3]`, with indexing and a few built-ins to go with them.
- **More comparisons.** `<=` and `>=`.
- **`natra yadi`.** Else-if chains without nesting blocks.

## Later

- Hash maps (dictionaries).
- Escape sequences in strings, such as `\n`.
- Better error messages for missing brackets, with a hint of what to type.

## Help build it

Lipi is open source. If you want one of these sooner, [open an issue](https://github.com/RusilKoirala/lipi/issues) or send a pull request on [GitHub](https://github.com/RusilKoirala/lipi).
